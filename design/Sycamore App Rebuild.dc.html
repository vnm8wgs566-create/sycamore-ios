The job, front and center
Where rank, staffing and "what's on now" got muted — and the screens that are missing.
2gFix first
Ranking has no flow

Import lands 42 kids "unranked" (1d) and the very next Groups screen is already ranked 1–25 (1o). The first sort — the product's reason to exist — has no screen. What exists is long-press drag, one row at a time, between folded cards (1p): fine for corrections, hopeless for 42 kids courtside.

Do: a Rank session — deal unranked kids into groups by tap, drag only to fine-order inside a group. Enter it from Groups whenever anyone is unranked, and straight after import review. Move "Partition by rank" out of Camp settings (1t) into it.
2hFix first
Assigning coaches is read-only

Every staffing gap is visible and none is tappable: "Needs a coach" (1k), "Add a coach" (1i), "Reassign" (1l) — all endpoints, no picker drawn anywhere. The codebase already stubs one (BlockCoachPicker).

Do: a coach picker sheet — who's free this block, one tap to place. The amber flag itself is the button.
2iFix first
"Now" is a whisper

At 9:41 the one thing a person wants — what's on, how long is left — is a grey 13.5px subtitle (1i). The current block never gets the emphasis treatment the design already owns for "your court" (1j).

Do: a Now card pinned first on Overview — block, minutes left, courts, next block, and the one action (Take attendance / Open your court).
2jNext
No needs-you roll-up on Overview

A coachless court, unmarked attendance and today's pick-up sit in three different tabs. Inbox counts "Needs you · 2" (1r) but home never says it.

Do: one strip under the pinned note — "Needs you · 2 — Match play has no coach." Tapping it lands on the fix, not the Inbox.
2kNext
Blocks can't be added or edited past first run

A populated day can't grow: no add affordance on 1k, no block editor anywhere — "start from a shape" exists only while Friday is empty (1f). The ⋯ on a block (1l) leads nowhere.

Do: a dashed "Add a block" row in the timeline + a block sheet (time, courts, coaches, note) behind the ⋯.
Getting around
Camps, venues, and the seams between first-run steps.
2lFix first
Camp switching is four taps deep

Overview → avatar → Profile (1s) → Your camps (1u) → Switch. Multi-camp is the product's founding premise, and the header never even says which camp you're in.

Do: the header names the camp; tapping it opens a switcher sheet — camps, venues, and a Camp settings shortcut. 1u stays for join / start / archive.
2mNext
Venue context is undefined

Venue scope is only real on Groups (chips, 1o). Overview and Schedule show courts from nobody-knows-which venue — with two venues in play (1t) that's ambiguous everywhere it matters.

Do: one venue scope, shown and switchable the same way in every tab header — one pattern, three places.
2nNext
First run drops you at the finish line

After "Import 42 players" (1d) the flow just ends — nothing routes to ranking, and empty Groups (1g) is written for a five-kid camp instead of the 42 you just imported. The empty states don't know about each other.

Do: import success routes into the Rank session (2g); every empty state points at the next unmet step — venue → kids → rank → blocks.
